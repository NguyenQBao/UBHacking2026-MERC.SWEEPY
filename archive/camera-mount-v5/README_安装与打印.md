# 20mm圆孔安装的25×25摄像头支架 v5

本版针对用户给出的圆孔半径10mm（直径20mm）、摄像头模块25×25mm设计。亚克力板厚暂按3mm，用户同意按此试装，未实测；不能据此称已精准适配。

## 结构

- 01底座＋立柱一体件×1：上法兰直径40、厚4；下定位柱直径19.4、长2.5。定位柱比20孔小0.6，目的是顺畅插入，不是过盈卡紧。中间4.5孔配M4螺栓。后偏13的双耳立柱给中央螺栓头和工具留空间；俯仰轴离亚克力上表面64。镜头实际高度还要加底盘离桌面高度、载框内镜头位置及俯仰角影响。
- 02摄像头俯仰框×1：外框37×37，中央避空22×22。配25×25板，边缘支撑重叠约1.5；不宣称匹配摄像头PCB安装孔。四个2.4绑带孔，用细尼龙线/细绑带及非导电软垫在无元件板边轻固定。先查背面元件及排线座避空，不可夹住或压住它们。若没有可安全接触的板边，要改成真实孔位安装。
- 03底部垫片×1：外径36、厚3，中孔4.5，放底板下面，分散M4夹紧力。
- 00a定位柱试件×1：先验证19.4柱能进入20孔。
- 00b、00c俯仰配合试件各1：8厚耳片、8.8夹缝，孔3.4配M3。

整套与之前扎带底座v4不同，不混用支架或摄像头框。

## 需要实物确认

1. 目标孔直径20，板厚3；最好卡尺测量。孔周围要有直径40的平整区域，上法兰才能压平；底部直径36的垫片不能碰电机、线缆或支柱。照片不能确认这些净空。
2. 底部定位柱长度2.5。底板3mm时，柱端与下垫片还隔0.5，不会先顶死而夹不紧板。如果板厚≤2.5，或你加了不同厚度软垫，需要重算柱长，勿强拧解决。柱长原则：上下法兰间需夹住的实际厚度减至少0.5。
3. 圆孔固定靠垫片夹紧摩擦力抗旋转；没有防转键，振动可能松动。先地面测试，可用现有槽加辅助绑带防转。不要为防转使劲拧裂亚克力。

## 紧固件（候选，先干装量长度）

- M4×20螺栓×1，M4锁紧螺母×1，金属平垫片×2。上下压紧板中间穿螺栓，底部螺母锁紧。底下需留螺丝尾和工具空间。
- M3×25螺栓×1，M3锁紧螺母×1，金属平垫片×2，穿俯仰双耳与载框耳片。只拧到角度不自行下垂，不夹裂打印件。
- 细尼龙线/合适细绑带、非导电软垫。不要将模块贴着树脂元件硬压。软垫位置需按真实板子选，不遮镜头。

## 打印顺序与方向 / Prusa MK4S

实际喷嘴/耗材预设由实验室确认。PLA原型、0.20层高、4圈外壁、上下5层、25%填充作为起点；立柱可用5圈外壁。

1. 先打00a、00b、00c。00a大圆片朝下，小柱朝上；实际试插时翻过来，小柱朝下。不能硬塞，尤其别用打印件撬亚克力。
2. 试件合格后，01按STL默认方向：定位柱端朝下、法兰上方立柱朝上。**法兰底面悬出的环形区域需要支撑**，不要把它当免支撑件。用切片器支撑绘制，只在法兰底面加从平台起的支撑，清理与亚克力接触面。定位柱可加brim，但去掉brim后要复查直径。3.4横向孔检查短桥，按需要局部支撑。
3. 02框体平面朝下、连接耳朝上打印；耳片横孔需看切片。03垫片平放免支撑。
4. 不整体缩放来解决配合。试柱偏紧先调整源文件PLUG_DIAMETER；叉耳太紧调整连接间隙。打印尺度仍为mm、100%。

## 安装顺序

断开电源，先拿试柱确认目标孔。

① 将01定位柱从上方插入亚克力圆孔，直径40法兰贴在板上面，立柱偏在孔的后方；载框让镜头朝标有FRONT的一端。
② M4螺栓加金属垫片，从01中央孔向下穿过。底板下面依次放03打印垫片、金属垫片、M4锁紧螺母。先手拧，确认法兰都压住板且柱没顶死，再轻锁。
③ 将02连接耳放进双耳，M3螺栓水平穿过，另一侧垫片和螺母，先保留可调节状态。
④ 摄像头25×25板用绝缘软垫避开元件，轻绑板边；镜头前方无遮挡，排线有松弛弯曲空间。
⑤ 实时看画面，调整俯角到能看清刷前工作区；别默认某个角度必然可用。先测10/20/30/50cm清晰度，再锁紧俯仰。固定后再做测距标定。
⑥ 地面慢速振动检查，确保底座不转、画面不抖、排线不会碰轮子或滚刷。只有固定可靠才做距离标定。

## 验证

6个STL已检查封闭、法线方向、正体积、单一实体、独立边拓扑和Z=0。按20孔及3厚的板做名义干涉计算；基座与亚克力不相交，定位柱留0.5不顶死，中央M4工具空间有留出。纯打印件俯仰-20至+50度每5度采样无相交；不等于实际相机角度范围，不包含PCB、螺丝、排线、底盘边缘、驱动板或机械承载验证。未切片或实物打印。


## 主控更新：Raspberry Pi 4B

主控已确认改为Pi4B。本支架安装于亚克力底盘圆孔、夹持25×25相机，几何尺寸不依赖主控型号，因此STL保持不变。Pi4B使用USB-C稳压5V/3A供电，摄像头接15针CAMERA/CSI。GPIO物理脚号沿用，查看最新4B接线图，不再用旧3B照片找接口。
