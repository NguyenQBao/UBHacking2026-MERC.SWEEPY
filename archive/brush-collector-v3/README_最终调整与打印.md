# METALSWEEP v3：刷子收集版 / MK4S

本版替代 v2 方案；“最终”指本轮布局调整完成，并非整机已验证。单位 mm、导入100%。不使用旧版探测臂、线圈架、侧置收集盒。所有件独立打印，孔位/配合以试片和实物为准。

## 本轮改变

- 180×150×4底盘前部开76宽缺口（X45至前缘90），供导料结构通过；四根支柱孔周围保留材料。缺口边角是原型直角，尚未做疲劳承载验证。
- 150×120×3上板增加摄像头安装孔，中心(65,±15)，M3孔3.4。Pi孔距58×49、孔2.9不变。
- 收集盒移至底盘中央偏前，装配中心X10,Y0；盒体70×80×28，含耳外包络82×80×28。前方+X开口，耳孔对应底盘(-30,±30)。盒底放底盘顶面。此盒无自动卸料和快拆滑轨。
- 增加70宽、50长导料斜坡试件；先验证刷子是否能把目标推上坡，未验证收集效率。实际坡口离地高度随车轮及支撑轮尺寸确定，不保证可直接接触桌面。
- 摄像头按Arducam B0033 / OV5647约25×24板外形设计开放载框；不宣称匹配PCB孔距。框背面镂空26×24，需用绝缘软垫垫高并在板边轻绑，不能压背面元件、镜头或排线。若无法避开元件，停用并修改；不强塞或强扣。

## 只打一个的试装件，不能当作已验证机构

- 06_brush_ramp_trial ×1：平底朝下打印。需要可调安装/夹持结构才能确定离地位置；当前不含已配合的坡道固定座。可先用夹具固定测试，位置确定后再做正式支架。
- 07_brush_support_trial ×2：先打1片。45×40×4平板，3.4宽调节槽仅试名义3mm轴，不是精密轴承座；底部两孔距28。未提供与底盘直接对齐的转接座，也未提供驱动电机反扭矩固定座。实际轴、轴承、电机定型后修改，不能仅靠松动轴槽长期运行。
- 10_camera_mast ×1：24×70×4平板，两个3.4孔间距50；打印平放，安装时立起。
- 11_camera_angle_foot ×2：L角支架，底孔和立面横孔3.4；安装组合、孔间距与俯仰角要干装。水平孔可能需要清理，先打1个。此支架组是通用试件，不宣称所有孔均能直接与上板组合连接；必要时需转接片。
- 12_camera_carrier_trial ×1：36×34框体、附12×12耳片，总高约44；M3耳孔调角，侧边四个2.4绑带孔。务必用实际摄像头试装并保留排线弯曲空间。先在10/20/30/50cm拍照确认近距可用，再定摄像头高度/角度。

## 打印参数与顺序

机器：照片标识Original Prusa MK4S，官方成型空间250×210×220。实际喷嘴由工作人员确认。软件PrusaSlicer，选实验室已验证的机型/材料预设，不直接使用其他机器的G-code。

PLA原型、0.4喷嘴条件下可从0.20层高、4圈外壁、上下5层、20–25%填充起步。大板单独一盘；全部带平底的件以平底着床、盒开口向上。45高柱竖放可加brim；薄板可用5–8 brim。最大底盘加8 brim约196×166，能放入标称打印空间，但要看切片边界。不要整体缩放。

顺序：两种试片 → 单个电机座/支柱/垫柱 → 用真实零件或纸板干摆 → 底盘 → 上板与补齐小件 → 摄像头试装组 → 刷子支撑/斜坡各试件 → 收集盒及传感器。上一阶段不通过先改，不整套重打。

## 仍缺少的实物与正式模型

现成软刷/刷条、刷轴及轴承、刷电机和联轴器、两驱动轮、万向轮、实际电机/电池/传感器型号。滚刷正式轴承座和驱动座、导料坡固定座、前罩/挡板、摄像头正式转接件仍需实测后完成。当前模型包不构成开箱可装的完整机器人。

电池需要另留空间；收集盒占用原先的中部电池区，要用真实电池干摆重排。Pi底面约Z58，不能据此认定整机总高度，车轮、摄像头和排线会改变外包络。

## 验证

14个STL：封闭、单一实体、法线方向、正体积、三角面边拓扑、Z=0通过。指定支柱/收集盒/摄像头底孔穿通及支柱附近材料保留通过坐标和实体检查。不是切片、强度、机构干涉或实物打印验证。独立结果在independent_stl_check.json。
