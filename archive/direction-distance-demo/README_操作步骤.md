# 碎屑方向与距离测试：固定相机原型

这是视觉测试程序，不连接GPIO，不驱动小车或舵机。当前只能用于固定相机、固定车身、平整桌面和稳定光照，背景相减识别的是“与空桌面不同的区域”，不是通用语义碎屑识别器。影子、反光、手也可能被标出。移动相机或车身后必须重拍空参考；不适合直接作为行驶中的检测器。

## 树莓派端

先确认相机可用：

```bash
rpicam-hello --list-cameras
```

近期Raspberry Pi OS可用apt安装（不要把Picamera2随便装进隔离的pip环境）：

```bash
sudo apt update
sudo apt install python3-picamera2 python3-opencv python3-numpy
```

解压本文件夹，终端进入其中，然后：

```bash
python3 debris_demo.py
```

程序默认只监听树莓派127.0.0.1:8000。在Mac终端另开窗口，用实际用户名和地址：

```bash
ssh -L 8000:127.0.0.1:8000 你的用户名@树莓派IP
```

保持此窗口连接，在Mac浏览器打开 http://127.0.0.1:8000 。如果8000被本机程序占用，可把隧道命令第一个8000改8001，再访问本机8001。

把文件传上Pi的一种方法（在Mac、解压后的文件夹上一级执行）：

```bash
scp -r debris-direction-distance 你的用户名@树莓派IP:~/
```

树莓派上再 `cd ~/debris-direction-distance`。不确定树莓派IP或还没连通SSH时，先完成网络连接。

## A. 先看方向（无需距离标定）

1. 摄像头固定在车前上部，镜头看向桌面。先检查不模糊、不倒置、不镜像。
2. 清空测试区，稳定灯光，点击“拍空桌面参考”。此步骤还会尝试锁定当前曝光及白平衡，避免自动曝光变化造成全图差异。
3. 在画面下部中央放一小片深色纸屑，手移开，观察绿色框和左/右方向。
4. 目标向右移，结果应显示右；向左同理。黄色竖线是画面中心，不一定是机器人真实中心线。
5. 方向未标定前仅按画面中心计算，没有角度和毫米距离。多个区域按面积排序编号，不是目标跟踪；编号可能变化。

阈值偏敏感时Ctrl+C停程序再用 `python3 debris_demo.py --threshold 40 --min-area 60`。目标与桌面灰度相似会漏检，先用高对比目标演示；不能把阈值降低到把所有阴影都当碎屑。

## B. 做桌面距离标定

选择一个机器人相对桌面坐标原点，例如刷子入口中央的垂直桌面投影；x向右，y向前。纸上画或胶带标出一个已知矩形，左右中心与机器人前向中心线对齐，矩形的远近边与机器人横向平行。

例如宽200mm、前后深200mm、近边距原点100mm：

```
           远左④ (-100,300) -------- 远右③ (100,300)
                  |                       |
                  |  在矩形范围内测距      |
           近左① (-100,100) -------- 近右② (100,100)
                         原点(0,0)
                         机器人
```

以上只是示例，不要把默认数值当成实测值。如果矩形不在画面中，选更合适的大小/位置，并输入真实尺寸。整个矩形需要处于清晰桌面视野内。贴在桌上的四角标记保持不动；如果移走了标定板或标记，须再拍空桌面参考以免留下“消失物体”假目标。

1. 点击“暂停画面并选四角”。
2. 按近左、近右、远右、远左点击4点，填真实宽度、深度和近边距离。
3. 点击“应用标定”。只有四边形范围内的变化区域会输出距离，不做区域外推。
4. 放碎屑：显示x右向偏移、y前向距离、sqrt(x²+y²)平面直线距离、atan2(x,y)右偏角。
5. 第五个独立点：量出真实x、y，点击“暂停并点击检查点”，再点其画面位置。比较error_mm。在近、中、远处至少各测一次，根据刷子允许误差判断是否够用。四个标定点自身拟合准确不能证明其他位置精度。

距离是桌面相对于自定义原点的平面距离，不是相机光心的三维距离。本版使用原始图像直接四点拟合，没有内参/畸变校正，结果仅近似，尤其广角边缘更差。薄小碎屑用区域中心代表位置；较高的物体中心不在桌面平面，测距有额外误差。

不要移动相机、改变俯角/分辨率/裁切；改变后清除并重做标定。车身俯仰、打滑/振动和不同桌面高度会影响映射。标定与参考只在本次进程内存中，不保存到磁盘；重启后重新做。

## 接入运动的下一阶段

当前程序没有目标关联/跟踪、连续帧确认、收集状态机或电机通信，只显示候选。准备控制小车时：

- 把固定背景检测换成能随相机移动的检测方式（受控颜色HSV或训练的目标检测器）。沿用固定相机-桌面几何标定，但有俯仰或高度变化需校验。
- 稳定跟踪同一目标，再输出横向误差；右偏角>0时使左侧轮更快。
- 低速短脉冲，停稳后刷新图像；丢失/过期图像停车。
- 独立桌沿检测和底层命令超时停车，地面先验证。

## 验证和限制

`python3 -m unittest -v test_demo.py` 使用模拟图像验证方向符号、已知距离、标定范围限制、空图、无参考、全景变化和坏标定。未在你的Pi3/OV5647实机运行；需要验证相机接口、曝光锁定、速度和实际误差。不承诺通用碎屑识别或距离精度。
