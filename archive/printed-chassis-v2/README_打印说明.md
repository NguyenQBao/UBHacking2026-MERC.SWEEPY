## 建议打印顺序

1. 先打印孔径试片和一个电机槽座，用真实螺丝、电机试装。
2. 确认底盘能放入打印床后打印上下板、支柱。
3. 检查电机、轮子、万向轮的高度及间隙，再打印其他附件。

可从 PLA、0.2 mm 层高、4 圈外壁、25% 填充开始；最终采用实验室材料预设。底盘/上板平面朝下，收集盒开口朝上，支柱竖放。均已以 Z=0 放置，可免支撑起步评估。薄板可加 brim 抑制翘曲，是否需要由切片预览决定。不要把 PLA 封闭贴近发热元件。

## 装配与适配边界

- 上下板四角孔中心为 (±65, ±48)。底板4 + 支柱45 + 上板3 = 52 mm；可选 M3×60 贯通螺丝配垫片螺母，先实测长度。装配前检查螺丝不碰电路。
- Pi 用 M2.5 螺丝、6 mm 隔离柱安装；螺丝长度按实际板厚和垫片选择。孔位参考官方 Pi 3B 机械图，打印后先干装确认：https://datasheets.raspberrypi.com/rpi3/raspberry-pi-3-b-mechanical-drawing.pdf
- 电机槽座默认绑带固定；放在底盘下方两侧，纵向沿 X，轮轴向外。电机、轴向和外形必须实测，切勿遮挡齿轮箱/散热或勒住导线。当前不含确定的轮轴、万向轮孔位；轮子装好后总宽会大于150 mm。
- 支柱净空间45 mm。电池需要封装和绝缘，绑带固定；先测电池和接口高度，避免与 Pi 上板碰撞。
- 探测臂可以沿 X 安装，中心暂放 X=85，近端两个槽中心对应底盘 X=30、60,Y=0；此时臂端为 X=155，即伸出车身65 mm。线圈外壳装上后的总长度和高度待测，不沿用概念图280 mm总长。
- 收集盒安装耳孔距已改为60 mm。以中心平移到 X=0,Y=58 时，耳孔对齐底盘 X=±30,Y=30；盒底安装在底盘顶面。盒体伸出底盘侧边约5.5 mm，需要检查轮子及取放空间。这是侧置盒，并非前置自动收集机构。
- 传感器板通过绑带装到角部；保持下视无遮挡。具体传感器固定孔、探测高度和电路尚未适配。
- 未包含磁体套筒、自动释放/升降机构、电机轮子、万向轮、线圈或电子元件。先测选定零件再做相应支架。探测干扰和防跌落功能均未验证，首次测试在地面进行。
