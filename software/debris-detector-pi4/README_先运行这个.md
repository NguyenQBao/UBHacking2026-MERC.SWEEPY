# Pi4B + OV5647 碎屑检测

本版先检测，不接GPIO、不控制车轮或刷子。浏览器显示640×480图像、绿色候选框、中心位置、数量和左右方向，右边显示检测掩膜。无需模型文件、云API、Flask或额外GPU。

新增训练采集接口：`/raw.jpg` 返回640×480原始视图JPEG，不含检测框和掩膜。配套 `debris-training` 工具可在Mac采集、每50张标注、累计训练与测试；需要同时更新运行中的app.py并重启才生效。采集前重启以恢复正常自动曝光，不要先拍背景参考锁曝光。

## 1. 安装（在树莓派终端）

Raspberry Pi OS Bookworm或更新系统，先确保摄像头已接好并可识别。接排线先断电，使用CAMERA/CSI而非DISPLAY。

```bash
rpicam-hello --list-cameras
sudo apt update
sudo apt install python3-picamera2 python3-opencv python3-numpy
```

通常能看到ov5647。如果命令不存在、相机列表为空或报错，先解决相机连接与系统支持，不要靠检测程序绕过。旧系统可能使用libcamera-hello，建议使用当前受支持的Raspberry Pi OS。通过apt使用系统python3，不要把Picamera2单独装进普通隔离pip虚拟环境。

## 2. 把解压后的文件夹复制到Pi（在Mac终端）

下载并解压本ZIP。终端进入包含 `debris-detector-pi4` 文件夹的目录，把下面用户名和IP替换为你的：

```bash
scp -r debris-detector-pi4 你的用户名@树莓派IP:~/
```

再连接Pi，运行：

```bash
ssh 你的用户名@树莓派IP
cd ~/debris-detector-pi4
python3 app.py
```

如果画面倒置，Ctrl+C退出后使用：

```bash
python3 app.py --rotate180
```

## 3. Mac浏览器查看

另开一个Mac终端窗口：

```bash
ssh -N -L 8000:127.0.0.1:8000 你的用户名@树莓派IP
```

保持两个终端连接，Mac浏览器打开 http://127.0.0.1:8000 。服务默认仅监听Pi的本机地址，使用SSH隧道即可访问；不需要在路由器开放端口。

也可以直接在Pi的桌面浏览器访问同一地址，此时不需要SSH隧道。

如果Mac的8000被占用：隧道改为 `ssh -N -L 8001:127.0.0.1:8000 用户名@PiIP`，Mac访问 http://127.0.0.1:8001 。如果Pi端8000被占用，先关闭旧版debris_demo.py或用 `python3 app.py --port 8002`，隧道目标端口也相应改8002。

## 4. 第一次测试：空桌面模式

1. 车轮电源先断开，相机和车身固定；拍摄桌面应清晰，先在正常环境光下等待自动曝光稳定。
2. 通过“暂停并选择区域”，点击矩形的两个对角，把机器人本体、刷子、桌外背景排除；默认蓝框可直接起步。
3. 移开手并清空区域后，点击“拍空桌面参考”。按钮会尝试锁定当前曝光和白平衡，再采5帧中值参考。
4. 在区域内放一个明显的小纸屑/零件。手移开，看绿色框和中心点。
5. 目标左右移动，观察LEFT/RIGHT，页面表格显示中文方向。中间±20像素内显示CENTER。方向相对画面中心，尚未标定为机器人刷子入口或世界角度。

默认差异阈值28、最小面积40px²、最大面积20000px²。太敏感：适当提高阈值/最小面积；漏检：先确认目标清晰并与桌面有颜色/亮度差，再适当降低。面积按轮廓面积过滤，不是实际平方毫米。

这个模式检测“与空桌面不同的区域”，不是理解垃圾含义。车或相机移动、光照改变、手、阴影、反光都可能使结果失效。差异超过ROI的25%会抑制本帧候选，要求检查/重拍参考，但小幅移动并不能保证被自动发现，必须由使用者保持固定。移动后重新清空测试区并重拍。

## 5. 颜色模式（用于明显颜色的演示目标）

1. 放一块纯色碎屑，如与桌面反差明显的红/蓝纸片，区域中避免存在大量同色背景。
2. 点击“暂停并取色”，在目标中央纯色部分点一下，程序自动切换颜色模式。
3. 取色依据对应原始画面9×9像素块，避免绿色框本身污染取色；目标过小时应先用较大色片。
4. 恢复画面后会框出满足颜色范围的区域。颜色容差可调整，不需要空桌面参考。此模式可在相机移动时继续寻找相似颜色，但并不识别“这是垃圾”，也不保证光照变化、模糊或遮挡下稳定。

OpenCV色相范围0–179，红色跨越179/0已专门处理。灰/白目标主要用饱和度和明暗匹配，容易与桌面混淆；先不要用白纸配白桌演示。掩膜中白色代表选中，尽量让它只覆盖目标。

## 6. 本版范围

- 输出多候选的框、中心像素、左右方向和横向像素偏移，不算距离、不控制电机。
- 编号按面积排序，每帧可变化，没有稳定ID、跨帧跟踪、三帧确认或分类模型。
- 小于几个像素或与背景无差异的碎屑，不能保证检测。要识别多种真实debris（尤其金属反光和相近背景），需要真实样本、检测模型或进一步视觉方法。
- 四点桌面测距可在固定支架后另接先前的距离程序；不能用框的大小直接当厘米。检测框消失不表示收集成功。
- 不具备防跌落或导航。以后接电机需加入目标关联、有效帧时限、独立桌沿检测和底层超时停车。
- 预览按浏览器轮询采集，每次处理耗时显示在页面，不承诺固定帧率。CTRL+C退出释放相机。

## 7. 离线检查及测试

不需要Pi相机就能在装有OpenCV/numpy的电脑上跑检测器核心测试：

```bash
python3 -m unittest -v test_app.py
```

可用一张碎屑照片和对应空桌照片验证界面（两者先保持同一相机位置；程序统一缩至640×480）：

```bash
python3 app.py --image scene.jpg --background empty.jpg
```

无需Picamera2，浏览器打开本机 http://127.0.0.1:8000 。单图片模式不是实时视频。

开发验证：8个模拟图像/参数测试覆盖空图、方向、ROI、面积、全局变化、取色、红色色相环绕及非法参数；另测HTTP预览、参考、设置和取色接口。尚未在你的Pi4B/OV5647实机运行；需实测清晰度、相机接口、速度和现场阈值。

## 局域网直接访问（新增）

本程序默认仍只允许本机/SSH隧道访问。要让同网设备直接打开页面，运行：

```bash
python3 app.py --host 0.0.0.0 --port 8000
```

已知这台Pi的IP为raspberrypi.local，同一网络设备浏览器访问 http://raspberrypi.local:8000 。IP改变后用hostname -I查新地址。0.0.0.0是监听地址，不是浏览器访问地址。页面无登录验证，同网能访问的人可看画面、拍参考及修改检测参数，这些状态是共享的。此选项用于可信局域网，不做路由器公网端口转发。校园/访客Wi-Fi若隔离客户端，即使同SSID也可能互访失败。若本机可开但其他设备不能开，先核对网络隔离和已启用的防火墙规则。

更新旧的Pi副本：先Ctrl+C停app，在Mac执行scp将本包app.py覆盖到pi@raspberrypi.local:~/debris-detector-pi4/app.py，然后用上述新命令启动。只更新app.py即可，原index.html兼容。HTTP服务已改为ThreadingHTTPServer，空闲浏览器连接不再阻塞其他页面请求；相机访问用锁串行保护。多人频繁查看仍会降低刷新速度，未做多用户负载验证。


## TCP通但网页超时的修复

新版使用多线程HTTP服务及10秒连接读写超时，增加 http://树莓派IP:8000/health ，不访问相机即可返回 {"ok":true}。如果health能打开而画面卡住，请检查相机占用、/state错误和程序终端输出。关闭旧进程、上传新的app.py再启动，旧进程不会自动更新。回归测试 `python3 -m unittest -v test_http.py` 验证一个空闲连接不影响另一页面及health请求。


## 误检较多：先调参，再按需要开形状过滤

先固定镜头与车身，使用稳定灯光，区域只圈平整桌面，排除轮子、导线、键盘、桌边；清空区域并移开手后重新拍参考。背景模式可以从差异阈值40、最小面积150、最大面积5000开始，逐项改动观察原画面和掩膜。它们是纸屑演示的调参起点，不是已用现场数据验证的最佳值。

新版有“纸屑降误检参数起点”按钮，同时设置最大长宽比8、最小填充率25%。最大长宽比排除细长轮廓，填充率排除框里只有少量线条的轮廓；会漏掉细长/稀疏的真实debris，因此检测螺丝、细线时应改大长宽比或设0关闭，并降低填充率或设0关闭。形状过滤默认均关闭，保持旧版行为；只是几何过滤，不能可靠区分手、阴影和垃圾。背景移动造成的变化也不能靠这两个过滤补救。

更新要同时上传app.py和index.html（或整文件夹），停止旧进程后重新启动，浏览器强制刷新。新版另修正设置下拉框被实时状态刷新覆盖的问题，编辑模式后可以正常点击“应用设置”。参数只保存在进程内存，重启后重新设定。

颜色模式误检多：重新点目标中央纯色区域，色相容差可从12降到6至8，明暗/饱和容差可从65降到30至40；范围太窄会漏检，现场验证后再决定。
