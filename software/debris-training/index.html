1 · Collect or import

Photos of the same table, light and layout belong to one split only. Change the scene name only when the place really changes; do not rename just to split neighbouring video frames.

Place the debris, move your hand away and keep the car still before capturing. Saved photos have no detection boxes. The camera service must support /raw.jpg.

Already have JPG / PNG / WEBP?

Imported in file-name order and split into batches of 50. Identical images are not added twice.

Photos and labels are stored only in the local workspace; back them up regularly.

ZIP from the Pi data collector?

Keeps each photo's scene and split (train/val/test). Label them one by one below. Duplicates are skipped.

2 · Draw boxes and confirm

Capture or import photos first.

Drag a tight box around every visible piece of debris. Delete a wrong box and redraw it. For photos without debris use the dedicated confirm button.

Ctrl/Cmd+S saves and moves to the next photo. You are warned before leaving unsaved changes.

3 · Train one round per labelled batch

Uses all confirmed training photos so far and fine-tunes from the last successful model. Val and test photos are never used to learn weights.

The first 50 photos only prove the pipeline works. Aim for independent scenes: train 30, val 10, test 10, each with some debris photos. Every round validates automatically and keeps the best epoch; it stops early only after 50 epochs without improvement. While there are few photos, Start fresh with 100 epochs is usually more stable than continuing the last round. Do not tune settings repeatedly against the test set.

No task started

Training runs on the computer running this studio (Mac / GPU recommended). The first round needs internet to download pretrained weights.

4 · Export training data

Download YOLO dataset (.zip)Download full backup (.zip)

YOLO dataset: confirmed labels only, standard images/labels/data.yaml layout; train directly on another computer, Colab or Ultralytics. Full backup: every photo (including unconfirmed) + manifest.json; unzip and run python studio.py --root folder to keep labelling. Exporting never changes the workspace.

Where are the files and how do I use the results?

Photos and labels: workspace/images, workspace/manifest.json. Data snapshot of each round: workspace/snapshots. Models and validation charts: workspace/runs/round_…. Test evaluations: workspace/evaluations. Pi models: workspace/deploy.

The model only proposes visual candidates; it does not prove the material or that collection succeeded. This studio never drives motors. Full steps: README.md.
