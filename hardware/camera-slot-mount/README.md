# Camera slot mount

[camera-slot-mount.stl](camera-slot-mount.stl): a holder that the camera board slides into from the top. Its square sleeve fits over the top of the main post ([camera-holder-vertical.stl](../cad-v8/camera-holder-vertical.stl), 10×10 mm, Ø4 mm holes 10 mm apart) and is fixed with two M3 screws or Ø4 pins through the sleeve and the post's two front holes. It is generated by [generate.py](generate.py); change the parameters and regenerate.

| Item | Default | Note |
|---|---|---|
| Board | 25×24 mm, slot 2.0 mm thick | Common OV5647 board size; slot = 1.6 mm board + 0.4 mm clearance. The Hiwonder board is **not measured yet**: measure width, height and thickness before printing |
| Space behind the board | 6 mm | For the ribbon socket / 4-pin socket on the back |
| Front lip | 2 mm on each side | Window in the middle for the lens; open top for inserting the board |
| Ribbon slot | 18 mm wide | Exits at the bottom of the holder and out behind the neck |
| Tilt | 30° | Lens points forward and down; change `TILT_DEG` |
| Sleeve | 10.4 mm bore, 22 mm deep | Holes 5 mm and 15 mm below the post top, aligned with the post holes |
| Outline | About 30.4×25.4×57.6 mm | Print lying on its side (see below); standing up has a small bed contact and wobbles |

Regenerate:

```bash
pip install manifold3d numpy
python generate.py
```

If the camera ends up upside down (ribbon at the top), set `rotate180` to true in `config.json` instead of changing the model.

## Slot-thickness test plate (PrusaSlicer)

[camera-slot-mount-variants.3mf](camera-slot-mount-variants.3mf): one plate with 4 parts, slot thickness 1.2 / 1.6 / 2.0 / 2.4 mm (single STL files in [variants](variants)). Each part lies **on its side** (holder side wall on the bed, 30.4 mm tall; about 2.4× the bed contact of standing up, and the layer lines run along the neck, which is stronger). Supports are set to automatic **organic** supports from the build plate only (they only hold up the overhanging sleeve). The 4 parts are in a row along Y, 12 mm apart, without overlap. The 3MF holds only the models and per-part settings, not a printer profile; PrusaSlicer uses the currently selected printer, filament and print presets (parts are centred for a Prusa CORE One 250×220 bed).

```bash
python generate.py --slot 1.2 --out variants/camera-slot-mount-slot1.2mm.stl   # same for the other thicknesses
python make_plate.py
```

Test-fit the board, keep the best one and recycle the rest.
