# V7 摄像头支架：结构件、螺栓、螺母、卡扣均可打印

用于20 mm安装孔、暂定3 mm亚克力板、25×25 mm摄像头的**试装版**。相机PCB裸板厚度暂按1.6 mm，未测量。未测量当前集尘盒，提供高度和前伸选项，不能保证任选一根就无遮挡。此包和旧V5零件不混用。

本包提供18个STL；实际装一套只需选6个主体件。摄像头、排线和原来的亚克力底盘不是打印件。

## 先看 assembly_preview.png

绿色立柱在亚克力上面，浅绿色大手拧螺栓从板下面穿过20孔，拧进立柱底座的内螺纹。上方橙色托架卡住相机，浅色背框扣在4个弹性销上；紫色手拧螺栓/螺母锁住俯仰。

“60/90/120”是俯仰轴相对底座顶面的高度；底座厚12，所以俯仰轴离亚克力上表面为72/102/132 mm。镜头高度还受托架位置、倾角与底盘离桌面高度影响，不能直接把立柱数字当镜头离桌面的高度。

forward45把俯仰轴相对直立版前移45 mm；相机装上后还会相对轴进一步前移。先临时举起相机确认刷前工作区再选立柱；只打印选中的一根。90mm_forward45只是装配图示例，不是已验证适配实车的推荐尺寸。直立版底座圆盘朝前的一侧为-Y，前伸版向-Y倾斜；朝滚刷安装。

## 首先确认的实物尺寸

- 安装孔约Ø20；螺杆外径18.2可穿入，它靠上下夹紧面的摩擦定位，**不是紧配合定位销**。
- 底座接触区域需要约44×44 mm的平整空间，底下还要能容纳约42×38 mm手拧头和手指；槽孔、线缆、电机不能妨碍夹紧。不要跨在凸起或悬空薄边上夹。
- 底板暂按3 mm，螺杆伸出14 mm。板厚2–5 mm的名义螺纹相位/干涉已计算，但实际咬合和强度未试；其他板厚须改长度。
- 相机板25×25，裸PCB厚度暂按1.6。夹框只接触PCB边缘，中央22×22避空；背框另有29×14开口给排线连接器，假定连接器朝托架-Y边、远离俯仰耳。必须核对正反面元件、镜头与排线座。若其他板边也有元件，须改支撑形状，不可硬扣。25×6×3连接器包络仅为名义试算，不是实际连接器测量结果。

## 打印顺序：先试件，再主体

### 第1轮：6个小试件

1. `00a_base_thread_screw_coupon` + `00a_base_thread_nut_coupon`：大螺纹配合。
2. `00b_pitch_thread_screw_coupon` + `00b_pitch_thread_nut_coupon`：俯仰小螺纹配合。
3. `00c_snap_post_coupon` + `00c_snap_retainer_coupon`：卡销扣合和拆卸。

螺纹应能用手转入至少2圈、转动顺畅。卡扣应能扣住并手动解开，观察分叉根部是否开裂。PETG小件拉丝会影响配合，先清理再判断；不要靠大力拧或敲打配合。

这些是**自定义粗牙**，不是标准M18/M8：底座最大直径18.2/螺距3.2，俯仰最大直径7.8/螺距2.0。只能配本包打印螺母。名义径向间隙0.35、轴向轮廓余量0.12；试件不合格先修改源文件的间隙参数，不要整体缩放STL。

### 第2轮：主体

先打印所选立柱及01底座螺栓，验证夹紧和遮挡；再打印03、04、05、06。不同高度、前伸版只用一根，不必全部打印。

## Prusa MK4S 打印设置起点

实际材料、喷嘴、打印板以实验室为准，本包不含G-code，没有伪装成已切片的文件。

- 结构件与卡销优先考虑PETG；PLA可试形状和螺纹，但卡销反复弯曲、长期夹紧和振动可靠性仍要实测。PETG的拉丝和细节质量需要调好。
- 假定0.4喷嘴，层高0.16–0.20，外墙5–6圈。立柱/托架可从30–40%填充起步；螺栓、螺母、卡销试件100%填充。
- STL已经按打印姿态落到Z=0，单位mm，比例100%。
- 01、05：手拧头平放，螺杆竖直朝上；06、00螺纹螺母孔轴竖直。**不要在螺纹内部自动塞支撑**。
- 02：底座圆盘平放，立柱朝上。前伸版是倾斜立柱，不是水平悬臂；60 mm前伸版的倾斜较大，先看切片过悬。叉耳的8.6 mm横孔及圆耳下缘按切片结果加局部、易移除的支撑，避免填满整个叉间隙。
- 03：大框前平面贴床、卡销及俯仰耳朝上。俯仰耳横孔按需要画局部支撑；卡销、分叉缝与卡肩不要被支撑包住。小卡销建议放慢外墙速度，以试件效果为准。
- 04、07及00c压框：平放；0.4垫圈需至少两层0.2，避免使用会跳过薄层的设置。

这是打印起点，不是现场验证过的高良率参数。先单独打试件，再决定批量摆盘，能更早发现堵料、拉丝和配合问题。

## 全打印装配顺序

1. 断开相机排线前先断电。把所选02立柱底座放在原前孔上方，让相机朝滚刷。
2. 01螺杆从亚克力下面穿孔，拧进底座。底座孔与螺杆中心对齐后缓慢起牙；仅手拧到不晃动。若底座会转，不能用猛拧补救，需重新评估底盘接触面或增加第二固定点。
3. **先不装相机**，试扣03和04，确认能拆开。分叉卡销从背框圆孔穿出并扣住；捏合卡销头两半后再抬起压框，避免硬撬框角。
4. 镜头朝03中央开窗，把PCB边缘放入短导向块围成的25.6 mm空间，排线座朝背框大开口、远离俯仰耳。确认元件、排线座都不被框压住，再扣04。PCB厚度或间隙不符先改参数；07只用于已确认需要的边缘填隙。相机图像若倒置，软件调整后整个采集/训练流程保持同一方向。
5. 托架10 mm厚连接耳放入立柱10.8 mm叉间隙。05从一侧穿过两个叉耳和托架，另一侧拧上06。稍微收紧后仍能调角度。
6. 开相机预览，先向下35–45°试调，让下沿尽量看到刷前近区、左右覆盖滚刷宽度，然后手拧锁角度。25–55°仅做了每5°的打印件名义干涉采样，不是包含真实排线/镜头后的保证可用范围。
7. 排线从背面留松弛弯曲，不能承受托架重量，也不能碰滚刷。先固定车身测试图像，再做地面振动试验；确认不转、不滑、不松、不抖后，才拍正式训练数据与做距离标定。

塑料螺纹/夹紧件有磨损和蠕变风险，是否能长期锁住相机需要实测。不要当作已完成承载或抗振验证的正式结构。回到同一角度应重新检查画面，不能只看螺母是否拧紧。

## 模型验证及源码

- `build_mount.py`：可编辑尺寸和公差；依赖manifold3d、numpy、trimesh。
- `verify_stl.py`：独立读取最终二进制STL，检查每条边正好被两个面共享、相反边方向、无退化三角、正体积与Z=0；仅Python标准库。
- `validation.json` / `independent_stl_check.json`：18个STL网格检查；3高度×2前伸×7角度的打印件及打印螺栓/螺母干涉采样；名义平板、裸PCB与螺纹配合检查。
- `draw_assembly.py`：从实际模型生成装配预览；绿色PCB、黑色镜头与亚克力板为示意，不在STL中。

尚未实际切片、打印或装到车上；未验证实际相机元件/排线/集尘盒净空、卡扣保持力、螺纹锁紧力、承载、蠕变和振动。网格通过不等于实体装配已通过。
