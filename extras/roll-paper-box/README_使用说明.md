# 带可拆上盖的卷纸盒：试装版

用途：普通卫生纸卷挂纸/抽纸，不是厨房长卷纸版。纸卷实际尺寸未收到，暂定最大长度115mm、满卷外径120mm。盒体外包络126×132×135，上盖厚板3，装好总高约138。内腔120×126，高132。底部放置纸卷，不带中心轴；抽纸顺畅性须实测。

先打印00a、00b小试片。上盖试片翻面嵌入盒状试片，感受定位裙边与壁的间隙，勿强压。如果偏紧，修改源文件LID_GAP后重生成；不要缩放整盒。试片只有短边接触，不能完全代表大盖子的翘曲，正式件仍需检查平整度。

正式件：01盒体×1，开口朝上；02上盖×1，大平面朝下、定位裙边朝上打印。装配翻转上盖，裙边插入盒内，让裙边缺口和盒体出纸口同向。上盖靠重力就位，无锁扣，不能倒置使用。前壁出纸口104宽12高一直通到上缘，避免打印长桥；不含刀片或切纸齿。换卷从顶部取盖。

MK4S打印：实际喷嘴/耗材预设由实验室确认。PLA、0.20层高、4外壁、上下5层、约20%填充起步；盒底平放可加5mm brim。无需将盒体倒扣，不应为内腔生成满盒支撑，先检查切片路径。顶部出纸口使前壁两侧分开，但两侧均由下层连续支撑。相对原小支架，这个盒体耗材与时间明显更多，实际用量以切片器为准，几何实体体积不是实际耗材量。

后壁是完整平面，可配适用于基材/塑料的双面胶，先清洁并按胶带说明等待后轻载试挂。承重、打印层面粘附、拉纸时剥离力没有验证；不保证墙漆无损。若用可拉伸胶条要预留拉片，不能把拉片藏死。先在桌上测试纸卷能转动、纸头能顺利从上缘前口拉出，再决定挂装。

所有4个STL通过封闭、法线、正体积、单实体及独立边拓扑检查；模型坐标中盒体及上盖出纸通道没有实体遮挡。未进行打印、实际抽纸、材料强度或粘贴承重验证。源文件build_box.py可改尺寸，依赖manifold3d/numpy/trimesh。
